ST 513 Mini Project 1

World Development Indicators Analysis

This repository contains my ST 513 Mini Project 1. The project uses SAS to analyze selected variables from the World Development Indicators dataset.

Project Objectives

The objectives of this project are to:

* Import and prepare an Excel dataset in SAS.
* Select appropriate categorical and quantitative variables.
* Create frequency tables and descriptive statistics.
* Produce cross-tabulations and graphical displays.
* Interpret the results in the context of global development.
* Present the analysis in a professionally formatted report.

Repository Contents

* instructions/ — Original project instructions.
* data/ — World Development Indicators dataset.
* code/ — SAS program used for data preparation and analysis.
* report/ — LaTeX source code and compiled final report.
